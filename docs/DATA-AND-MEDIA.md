Additions made after curation:
- `BS.meta.onSaleCount = 4920` (real number of discounted products from the Store API, use in "Peržiūrėti visą išpardavimą (4 920)").
- `BS.meta.shippingFacts = {cost: 3, dispatch: '1-2 darbo dienas', freeFrom: '2 prekių'}` (from the current site: delivery 3 €, dispatch in 1-2 working days, free from 2 items).
- `BS.collections.dealInfo.text` contains an en dash; display the spec copy instead: "Itališkas stilius, kurio verta laukti visus metus. Šį mėnesį su ypatinga kaina."
- Review images: `assets/img/reviews/review-N-product.jpg` and `review-N-photo.jpg` (real customer photos; review 7 has none).
- Max discount in data is 80 % (`BS.meta.maxDiscount`). The current site still claims "iki 60 %"; the demo uses the real data.
- `BS.brandLogos[slug].box = {x, y, w, h}`: the visible-ink bounding box inside the PNG, in file pixels. The files are NOT trimmed: each keeps 16-30 px of transparent padding per side (Tommy Hilfiger's ink is 27 of 63 px tall). Size logos by `box`, not by a padding guess.
- Copy normalised in products/reviews (core fix): every percentage is written with a no-break space ("50 % perdirbtų"), and the Furla 175775 desc typo "nepakeičiama aksesuaras" is fixed. `BS.util.dashFree()` applies the same percentage rule at runtime.
